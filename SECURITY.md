# Security

Only the current version on `main` receives fixes. Run a maintained Node.js 22 patch and keep dependencies updated.

Please report suspected vulnerabilities privately using this repository's GitHub **Report a vulnerability** option when available. If it is unavailable, contact the maintainer through the contact method listed on their GitHub profile; do not put exploit instructions, credentials, customer URLs or personal data in a public issue.

Include the affected commit, a controlled reproduction, observed impact, and suggested mitigation. Do not test against installations or domains you do not own or have permission to assess.

Production operators should read [deployment guidance](docs/DEPLOYMENT.md), enable HTTPS, protect database backups, keep SMTP secrets private, and enforce outbound network restrictions. The public demo uses synthetic data and allows no mutation or arbitrary checks.

Relatos podem ser enviados em português. Não publique segredos ou detalhes de exploração em uma issue pública.
